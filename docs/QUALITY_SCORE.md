## 스코어 구조 (총 100점)

| 항목 | 배점 | 설명 |
|------|------|------|
| A. 타입 안정성 | 20점 | TypeScript 타입 명확성 |
| B. 컴포넌트 설계 | 20점 | Server/Client 분리, 단일 책임 |
| C. 컨벤션 준수 | 20점 | 네이밍, 파일 구조, import 순서 |
| D. 에러 처리 | 20점 | API 에러, 빈 상태, 로딩 처리 |
| E. 성능 & 보안 | 20점 | 렌더링 최적화, 환경변수, 보안 |

---

## A. 타입 안정성 (20점)

```
20점 — 완벽
  - any 타입 없음
  - 모든 props/return 타입 명시
  - 타입 가드 또는 조건부 체크 적절히 사용
  - API Route 타입은 src/types/ 에 분리

15점 — 양호
  - any 1~2개 (불가피한 경우)
  - 대부분 타입 명시
  - 타입 단언(as) 최소화

10점 — 보통
  - any 3~5개
  - 일부 타입 누락
  - 타입 단언 남발

5점 이하 — 미흡
  - any 6개 이상
  - 타입 거의 없음
```

---

## B. 컴포넌트 설계 (20점)

```
20점 — 완벽
  - Server/Client 올바르게 분리
  - 단일 책임 원칙 준수
  - 컴포넌트 500줄 이하
  - 재사용 가능한 구조

15점 — 양호
  - 대부분 올바르나 일부 책임 혼재
  - Client 컴포넌트 소폭 과다

10점 — 보통
  - Client 컴포넌트 남용
  - 컴포넌트 내 여러 책임 혼재
  - 500줄 초과

5점 이하 — 미흡
  - 구조적으로 잘못된 설계
  - Server에서 처리해야 할 것을 Client에서 처리
```

---

## C. 컨벤션 준수 (20점)

```
20점 — 완벽
  - 파일/폴더 네이밍 규칙 준수
  - import 순서 준수
  - export 방식 준수 (named/default)
  - 커밋 메시지 형식 준수

15점 — 양호
  - 대부분 준수, 소소한 불일치 1~2개

10점 — 보통
  - 네이밍 불일치 다수
  - import 순서 혼재

5점 이하 — 미흡
  - 컨벤션 대부분 미준수
```

---

## D. 에러 처리 (20점)

```
20점 — 완벽
  - 모든 fetch/API 호출 try-catch
  - 빈 상태(empty state) UI 처리
  - 로딩 상태 처리
  - 사용자 친화적 에러 메시지

15점 — 양호
  - 대부분 처리, 일부 빈 상태 누락

10점 — 보통
  - API 에러 처리 부실
  - 빈 상태/로딩 처리 없음

5점 이하 — 미흡
  - 에러 처리 거의 없음
```

---

## E. 성능 & 보안 (20점)

```
20점 — 완벽
  - 불필요한 리렌더링 없음
  - NEXT_PUBLIC_* 외 민감 변수는 서버 전용
  - 이미지 Next.js <Image> 사용
  - 하드코딩 없음 (상수/env 분리)
  - dangerouslySetInnerHTML 미사용

15점 — 양호
  - 대부분 양호, 소소한 최적화 여지

10점 — 보통
  - 일부 불필요한 리렌더링
  - 환경변수 처리 아쉬움

5점 이하 — 미흡
  - 민감 정보 노출 위험
  - 심각한 성능 문제
```

## 자동 FAIL 조건 (점수 무관)

아래 중 하나라도 해당하면 즉시 FAIL:

```
🔴 any 타입 3개 이상
🔴 실제 API 키/비밀번호 하드코딩
🔴 DO_NOT.md 항목 위반
🔴 npm run build 실패
🔴 Hydration 오류 발생
🔴 .env.example 에 실제 키 포함
🔴 API Route 타입을 컴포넌트에서 직접 import
```
